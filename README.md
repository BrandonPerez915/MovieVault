# MovieVault
MovieVault is the complete source code for a Letterboxd-inspired platform designed to explore movie information, discover details, and share reviews and comments.

The app allows users to log watched movies with the option to give them a rating between 0-5 with half points such as 1.5 (though only ratings from 0.5 to 5 are taken into account). For rated movies, a review is added and users can choose whether or not to add a like indicating personal enjoyment. It is also valid to omit the rating, like, and review set after logging a watched movie. A user can also add or remove a movie from any list they create.

The application allows adding users to see if people you follow have watched a specific movie, what review and rating they gave it, as well as generally viewing their profile to see movies they have watched, their favorites, and other created lists. Additionally, there are user interactions such as liking other users' reviews and lists.

Our platform allows searching for movies by predefined filters such as genre and country, rating, decade and director, or a director-actor pair. There are more open search functions by comparing user-entered terms when searching for movie titles or their synopses. Reviews can be filtered based on a given rating by a number of users, and comments can be filtered by keywords.

Furthermore, there is a logging functionality that records various user interactions with the system to create activity histories, covering personal actions such as consumed movies, movie ratings with associated elements, list creation and updates, as well as social interactions between users such as following each other and giving likes to reviews or lists.

Out of scope: Watching movies within the platform. Informing the user where the movie is streaming. Integrated chat for private discussions. Reviews only feature likes. Collaborative lists cannot be created. Only movies can be reviewed, not authors or directors.
